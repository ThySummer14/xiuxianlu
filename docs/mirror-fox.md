# 镜狐与渡口狐灯

## 玩家可见的机制

16层起遇到镜狐，20层会遇到第一只镜狐王。旧山魈的蓄力打断仍保留。镜狐到半血时将剩余妖气分成真身、烈影与障影：

- 烈影存活时，妖狐攻击为普通扑咬的120%；清除后降为75%。
- 障影存活时，对真身的伤害为65%；清除后恢复全额。
- 魔窟面板有自动、烈影、障影、真身四个目标。分影前只记录预选，半血分影后生效；分影后也可改变目标。
- 挥剑与剑侍使用同一目标。自动依次清烈影、障影、真身；指定幻影散去后回到自动。选择动作不会重置妖狐攻击计时。
- 不要求快速反应或连续点新按钮；强者可直接用过量伤害结束整场。原有归山、温养、返回闯关按钮的位置不变。

两影同时有文字和不同形状：烈影带火焰纹，障影带盾纹。复用现有狐妖主体和少量原生路径，不增加图片下载、解码或新的世界命中层。手机按钮脚本检查覆盖320/360/390/430px，目标区域宽高均至少44 CSS px；这不等同于真实手机画面验收。

## 选择与成长

16层解锁可选的“渡口狐灯”见闻。第一步可选择静心咒（永久将烈影增伤从20%压到5%，只影响镜狐），或立即获得最多6点有效功法领悟；满领悟的老存档获得有上限的修为替代。

清除双影并击败真身后可复命，选择仙缘+1（打坐修为+3%）或剑心+1（挥剑伤害+2%）。剧情阶段先推进再发奖励，连续点击不能重复领取。直接击败仍带幻影的真身可正常过关，但这一场不完成“辨尽双影”的见闻；以后仍有机会。自动清影同样可完成见闻。

## 血量、时间和收益预算

原层级总血量为H。前半场消耗0.5H；分影时剩余0.5H重新分为真身0.3H、烈影0.1H、障影0.1H，没有凭空增加生命。过量伤害继续传向下一个有效目标；清除幻影不结算斩妖、修为、灵石、领悟、贡献或装备。只在真身死亡后结算一次原关卡奖励。

常量在`assets/balance.js`的`MIRRORFOX`集中列出。自动完整清影的伤害预算仍为H；强攻真身需承受护体减伤与烈影增伤，是否更快取决于攻击节奏和暴击，不能只看总血量推断所有策略的耗时。

`node --max-old-space-size=128 --expose-gc scripts/mirror-study.cjs`生成[配对模拟](mirror-study.json)。6个成长样本、6种策略，各用20个分散的确定性随机种子。比较生产代码中同层普通狐妖和镜狐，主动输入为2次/秒，没有战斗中购买升级。每批显式回收，串行执行；早期一次无上限进程退出码137，未据此推断原因。
