# 存档保险箱

进度保存在当前浏览器/设备，不会上传到服务器；清理网站数据可能清除它。建议在较大突破后导出一份JSON文件，并在浏览器下载列表确认文件确实保存。

## 正常备份与跨浏览器恢复

1. 设置 → 存档保险箱 → 导出当前存档。
2. 在需要恢复的浏览器打开保险箱 → 导入备份文件。
3. 先核对境界、灵石与时间，再点击独立的“确认恢复”按钮。
4. 当前进度会先留在“恢复前的进度”。恢复错误时可从这栏撤回。

导入仅在浏览器本地读取，限制1MB，不会立即覆盖角色。取消文件选择或预览，不会改变修行。无法识别、损坏、未来版本的文件不会被确认恢复。旧版可识别存档通过现有迁移流程读取。

## 使用自动保留的本机备份

保险箱提供最近启动备份、更早启动备份，以及恢复前的进度。不可读取的数据仍允许导出留存。若标题页发现当前档无法读取，会先进入恢复流程，不以空白新角色覆盖它。

恢复不追加旧档的离线收益，恢复后从当前时间重新计算。若无法先保留当前进度，或无法写入目标存档，恢复会中止。请先导出文件，不要清理浏览器数据。

## 保存失败

本地存储额度不足、权限限制等失败会显示提示和状态，不再静默声称已保存。即使本地写入失败，仍可从内存导出本次修行。下载动作只能被请求，浏览器仍可能拦截或等待确认，所以请检查下载结果。

微信小游戏保留原存储接口与本机备份恢复；本次文件导出/导入面向网页版。

## 验证边界

新增18项回归检查，覆盖失败写入、恢复预览/取消/重复确认、恢复中切后台、保护当前档、撤回恢复、旧数值迁移、导出再导入、损坏文件拒绝、临时Blob URL释放和过期文件读取。用真实生产处理函数与模拟浏览器接口验证，不等于已通过真实浏览器文件选择器/下载或视觉验收。

实现依据：[Storage.setItem](https://developer.mozilla.org/en-US/docs/Web/API/Storage/setItem)、[下载属性的限制](https://developer.mozilla.org/en-US/docs/Web/API/HTMLAnchorElement/download)、[Blob URL](https://developer.mozilla.org/en-US/docs/Web/API/URL/createObjectURL_static)、[FileReader](https://developer.mozilla.org/en-US/docs/Web/API/FileReader/readAsText)。
