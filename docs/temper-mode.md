# 温养与闯关的进度

温养反复经过21→22→23→24→25→21是有意设计的循环刷取，不是25层上限。温养区间会根据已通关纪录、当前秒伤和气血选定，避开未通过的层与首领；闯关则从独立保存的`towerFloor`继续向前。

原界面只写「温养·积累」，不够明确，容易让人误以为卡层。此外，标题摘要与一个任务进度曾读取临时刷取楼层，使已完成的进度看起来回退。本次修正：

- 进入前预览「21–25层·不推进」；温养中明确显示循环区间及原闯关进度。
- 增加「返回闯关」操作，直接接回玩家自己保存的楼层。可能是26、41、71等，不擅自假定是26。
- 切换沿用当前气血，不免费恢复、送资源或结算未击败的妖怪。也可以先归山养好伤，再继续闯关。
- 切换后原按钮位置成为状态说明，重复点击不会立刻触发另一个动作。
- 标题摘要、首个首领任务使用本世闯关进度；不把温养楼层或往世最高纪录当成本世推进。

复现与验证：真实生产脚本得到21→22→23→24→25→21，存档的闯关进度仍为26；返回后从26继续，可通过30层首领并保存到31。另测试了真实前线为41/71的情况、离线回归、失败归山、重载、重复点击、拖动取消，以及360/390/430px下完整Android点击事件序列。全部140项回归通过。

温养循环、收益公式、离线收益、已获资源及存档格式均未改。无需清档或重开角色。
