# 修仙数值与留存节奏研究

研究日期：2026-10-05。原始版本：`c8a0af3`。本研究只区分可验证的来源与设计推论，不把网页阅读或模拟称为真人试玩。

## 实际阅读的同类材料

1. [Immortality Idle 官方源码仓库与说明](https://github.com/immortalityidle/immortalityidle.github.io)：阅读项目说明，确认其以跨越多世的修炼、轮回累计为核心。也打开[在线游戏](https://immortalityidle.github.io/)，但没有完成交互试玩。设计推论：转世需要明确保留的成长与更快的下一世，不能只是重置按钮。
2. [Myriad Immortal Sect 官方站](https://idlecultivation.com/)：阅读页面中的修炼、地图、突破与离线说明；作者把修炼进度与外出资源分开，并明确离线降速、境界/寿命目标。未注册或试玩。设计推论：本作既有闭关与魔窟，应该令两条路线互相帮助，而非新增无关系统。
3. [Cultivation Idle 开发者 Steam 页面](https://store.steampowered.com/app/4727230/Cultivation_Idle/)：阅读开发者对资源分配、装备/功法、阶段目标与离线积累的介绍。商店描述不等于系统已经被我们验证。设计推论：投资回报应可理解，靠资源配置影响下一次突破，不应让每种选择最终只有更大的数字。
4. [Idle Cultivation World 作者页与更新日志](https://veudaimonia.itch.io/idle-cultivation-world)：作者列出奖励预览、锻造边际收益和重置确认的修正，评论中可见玩家对过早数值溢出、内容同时出现的担忧。没有运行嵌入游戏。设计推论：优先验证有限数值、解锁节奏、收益与成本的一致性；并把选择代价提前告诉玩家。

没有复制竞品代码、素材或叙事。上述描述只作设计参考，不把销量、评分、评论当作本作体验结论。

## 实际仓库检查

原仓库只有已发布的静态 JS/HTML/PNG，无 package.json、测试、README、AGENTS.md 或 `.agents/skills`。已直接读取全部数值配置与主循环、存档、离线、宗门、魔窟、突破、坊市逻辑。测试用 Node VM 执行原始脚本。

### 测得的原始问题

- 茶摊配方的额外产出随境界按 1.5 倍增长，但配方价格按 2.6 倍增长。4 间茶摊的首级配方在 S0 回本约 202 秒，S8 约 4.57 小时，S16 约 15.52 天。突破反而毁掉投资价值。
- 组合存档样本在完整重载后的一小时离线修为是 87,192,855，切回标签页却只给 13,733,753；灵石分别为 10,834,139,853 与 2,485,341,216。原因是标签页快照漏掉领悟、配方、宗门、仙缘等字段。
- 生死顿悟与九转还元篇没有作用于在线打坐；宗门暴击功法没有作用于实际暴击；传功对道基和悟道经重复乘算。
- 到达道祖大圆满后仍能继续突破；转世动画结束会错误调用普通突破并免费升一小境界。
- 利润配方最高层级只由界面禁用控制，底层购买函数没有上限校验。

完整原始数值见 `balance-baseline.json`，测试是公式/真实主循环模拟，不能据此声称主观“爽感”已经被验证。

## 迭代原则

1. 先修收入和成长承诺未兑现的缺陷，确保线上线下同一套账。
2. 以秒数/回本时间设计，而非凭空放大数字。保留原有存档、核心数值乘区与玩法。
3. 大境界应出现短暂准备与显著释放；随后能突破旧魔窟阻力，并有可理解的新目标。
4. 明确每次变化的测试、模拟假设和未验证部分；随机奖励不能是唯一可行路线。

## 第二轮：准备、突破、兑现（2026-10-05）

### 可调目标，而非已验证的留存承诺

首个15分钟应体验至少一次大境界、选择功法或投资、一次魔窟受阻后主动准备；30分钟仍有新功法/更深魔窟/投资阶梯可达；60分钟应留有下一大境界与轮回目标。比较四类输入策略，不能只奖励连续点击。

### 已实现

- `XB.BALANCE` 集中暴露门槛、境界释放、经济增长、机缘上限等参数。
- 小境界战力/修炼×1.3，大境界×2.25；大门前有1.6倍准备门槛，破境后气血回满，展示新功法。
- 坊市增长与战斗成长分离；配方只随自身阶数涨价，购买前显示当前回本时长、实际单店产出。投资配方成为真实可用的选择。
- 传功按最终收益封顶为当前境界35%，不再随机跳过整段功法解锁。
- 新增“温养历练”：依据剑侍秒伤与气血选择已打通的五层非Boss区域，积累装备、贡献和领悟；不增加推进纪录，低血时归山。一次进入固定循环范围，途中升级不会意外跳上Boss层。
- 同一道障碍不再可通过反复重伤刷满永久顿悟；新敌人有完整起手时间。
- 不下魔窟也能筑基立业：筑基时尚无茶摊的修士获得一间茶摊。
- 旧存档保留境界、灵石、装备和已买升级，按新旧门槛比例迁移当前修为，保留进度百分比及超过门槛的积累。数值版本单独记录，避免重复迁移。

### 同策略、五随机种子的真实主循环模拟

完整结果与四种策略说明见 [`balance-matrix.json`](balance-matrix.json)，固定种子为7、42、123、2026、65537；每策略每版本5次。模拟每50毫秒推进真实主循环，图形渲染省略，不注入灵石或修为。自动策略会在失败后选择温养、成长后再闯关；原版没有该选项。没有真人试玩，也不把这些结果视为留存预测。

|偶尔查看，30秒后不点击，60秒决策|19 / 33 / 59|8 / 15 / 24|363秒|843秒|0 → 10|

候选首金丹的五种子范围：主动295–375秒，偶尔查看783–903秒，投资363–453秒，探索319–349秒。20个候选样本均未在一小时内跳到终境；原版20个样本均到达终境。温养提供了推进受阻后的产出路线，偶尔查看的中位重伤次数40→16。原版达到终境后提前结束，所以伤次数不能被当作完全等时的死亡率比较。

这些结果支持“内容不再在第一段会话里被随机奖励吞掉，投资与修炼路线都能推进”的结论；不支持“人会觉得一定好玩”的结论。后续仍需浏览器视觉/触屏验证，以及更长时段、离线归来、转世收益的独立测试。

## 第三轮：离开游戏也不会吃亏

新增返回玩家专项回归测试，先验证7项失败，再逐项修复：

- **原始标题页覆盖存档问题**：未点“继续”便切后台，会把尚未加载的空白角色写入原存档。现在只有实际进入修行后才可保存；标题页与关闭页面均受保护。
- 1–44秒切后台也结算，并保留小数修为，避免频繁短切换损失进度；只有45秒以上才弹离线收获。
- 后台主循环暂停，归来统一结算一次，避免某些容器仍跑动画帧时双倍算账。
- 离线也养伤：按丹堂恢复加成分段计算重伤期惩罚与气血恢复。长期离开魔窟安全归山，短切换保持原战斗。
- 离线收获关闭后恢复此前尚未选择的机缘，不吞掉玩家的决定。
- 拒绝NaN、无限大和倒退的时间差。
- 修复第二轮引入的转世后重载前沿错误：本世第1层与历史最深120层分开保存，不会把刚转世的角色扔回旧高层。

4小时单种子推进补充测试（第二轮不可变提交01541ef）：约6989秒首次达到轮回解锁的渡劫初期，8277秒到真仙，4小时为玄仙大圆满；此为固定自动策略的一次运行，不代表玩家平均时长。更长时段与轮回投资价值继续单独评估，不用短会话数据外推。
